### 1. Visual Direction & Consistency Standards

All images must adhere strictly to these artistic and production rules:
* **Authentic Educational Environment**: Modern Indian Intermediate Junior College context (bright, clean, well-equipped science laboratories, tidy lecture halls, serene academic courtyards).
* **Color Harmonization**: Primary science palette matching the website design: Deep Navy (`#142B45`), Medical Green (`#16866A`), Subtle Mint/Teal (`#159A91`), Warm Gold highlights, and clean White architectural elements.
* **Lighting & Atmosphere**: Natural soft ambient daylight, clean laboratory fluorescent or window illumination, professional editorial sharpness, high dynamic range.
* **Subjects**: Young Indian college students (aged 16–18, Class 11 & Class 12 / Intermediate Junior & Senior) wearing clean, generic collegiate attire (neat white lab coats during lab sessions, modest generic academic uniforms or casual smart shirts). Natural expressions: curious, engaged, attentive, respectful pair-study dynamics.
* **Strict Exclusions**:
  * **NO** logos, text, signs, badges, or emblems.
  * **NO** college names, university seals, or brand titles.
  * **NO** watermarks, signatures, or camera stamps.
  * **NO** disturbing medical or surgical imagery.
  * **NO** AI distortion, hyper-fantasy saturation, or unnatural facial geometry.

### 6. Step-by-Step Instructions for Replacing Placeholders

When you generate the images using Google Flow:
1. **Save Output Files**: Name each generated image exactly according to its assigned filename (e.g., `hero-bipc-college.webp`, `campus-building.webp`, etc.).
2. **Place in Image Directory**: Copy all generated `.webp` files directly into:
   ```
   bipc-junior-college/assets/images/
   ```
3. **Seamless Replacement**:
   In any HTML page, wherever a placeholder container exists:
   ```html
   <!-- Current Placeholder -->
   <div class="img-placeholder ph-hero">
     ...
     <span class="ph-filename">hero-bipc-college.webp</span>
   </div>
   ```
   Replace it with the actual HTML `<img>` tag:
   ```html
   <img src="assets/images/hero-bipc-college.webp" alt="BiPC Junior College science laboratory and academic learning" class="img-fluid" loading="lazy">
   ```
   The CSS class `img-fluid` (`max-width: 100%; height: auto; border-radius: var(--radius-lg);`) ensures instant, clean responsiveness across all devices.
